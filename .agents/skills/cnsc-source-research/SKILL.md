Consultar primero robots.txt y HTTP público. Inspeccionar HTML real: título, identidad, categoría, publicación y paginación. Separar índice de buscador de acceso HTTP verificado. Documentar URL, campos, selectores, frecuencia propuesta, estabilidad, fecha de verificación y restricciones en docs/SOURCES.md. No asumir frecuencia editorial ni estado vigente a partir de resultados antiguos. Guardar fixture real sanitizada y probar cambios de estructura.
